# 스파이더 센스 테스트

학교 행사 부스용 반응속도 스테이션. 철자가 **맞는** 영어 단어가 뜨면 최대한 빨리 누르고, **틀린** 단어가 뜨면 3초간 참는 go/no-go 게임입니다.

- 빌드 도구 없는 정적 사이트 (HTML + CSS + JS 한 파일)
- 태블릿 터치, 마우스 클릭, 스페이스바 모두 지원
- 기록판은 브라우저 `localStorage`에 저장 (기기별로 따로 쌓입니다)

## 파일 구성

```
index.html   화면 + 게임 로직 전체
words.js     단어 목록과 설정 — 보통 여기만 고치면 됩니다
README.md
```

## 배포하기

### 1. GitHub에 올리기

```bash
git init
git add .
git commit -m "스파이더 센스 테스트 스테이션"
git branch -M main
git remote add origin https://github.com/사용자명/저장소명.git
git push -u origin main
```

### 2. Vercel에 연결하기

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인
2. **Add New → Project** → 방금 만든 저장소 **Import**
3. Framework Preset은 **Other**, Build Command와 Output Directory는 **비워둠**
4. **Deploy**

빌드 과정이 없어서 20초 정도면 끝납니다. 이후 `git push`할 때마다 자동으로 다시 배포됩니다.

> Vercel CLI를 쓴다면 폴더에서 `npx vercel --prod` 한 줄이면 됩니다.

### 로컬에서 확인하기

`index.html`을 브라우저로 바로 열어도 되지만, `file://`에서는 일부 브라우저가 `localStorage`를 막습니다. 이렇게 여는 편이 안전합니다.

```bash
npx serve .
```

## 내용 바꾸기

### 단어 목록

`words.js`에서 `[올바른 철자, 틀린 철자]` 형태로 추가하거나 지우면 됩니다.

```js
["receive", "recieve"],
["necessary", "neccessary"],
```

교과서 단어로 교체할 때 두 가지만 확인하세요.

- 쌍의 개수가 `ROUNDS`보다 많아야 합니다 (기본 10개)
- 영국식 철자를 오답으로 넣지 마세요. `favourite`, `colour`, `centre`는 전부 맞는 철자입니다

### 난이도

같은 파일 아래쪽 `GAME_CONFIG`에서 조정합니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `ROUNDS` | 10 | 한 판의 라운드 수 |
| `GO_COUNT` | 6 | 그중 눌러야 하는(철자가 맞는) 라운드 수 |
| `WINDOW_MS` | 3000 | 단어가 떠 있는 시간(밀리초) |
| `TOP_N` | 10 | 기록판에 보관할 인원 |

`GO_COUNT`를 높이면 누르는 습관이 강해져서 참기가 더 어려워집니다. 저학년이면 `WINDOW_MS`를 3500~4000으로 늘려주세요.

### 점수 계산

```
총점 = (맞춘 라운드 수 × 100) + 속도 점수
속도 점수 = 누른 라운드마다 max(0, (1200 - 반응시간) ÷ 10)
```

정확도가 먼저고 속도는 보너스입니다. 다 찍어서 누르면 점수가 안 나오도록 한 구조예요.

## 부스 운영 메모

- 우측 상단 **전체화면** 버튼으로 브라우저 주소창을 숨길 수 있습니다
- 태블릿은 자동 잠금을 끄고 밝기를 최대로
- 한 판에 약 30~40초. 대기줄이 길면 큰 화면에 미러링해두면 구경거리가 됩니다
- **기록 초기화**는 되돌릴 수 없으니 행사 끝나고 누르세요
